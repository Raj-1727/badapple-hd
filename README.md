# badapple-hd
-----

This is the upgraded version of my [badapple-py](https://github.com/Raj-1727/badapple-py) project. This badapple player allows you to play badapple in your terminal in the highest quality possible

-----

# Installation

## 1. Using github
```
git clone https://github.com/Raj-1727/badapple-hd
cd ~/badapple-hd
```
## 2. Using an AUR helper

```
yay -S badapple-hd
# or
paru -S badapple-hd
```
-----

# Usage

```
python badapple-hd      # if running from the cloned repository
# or
badapple-hd             # if installed from AUR
```
---

# Controls
```
q - quit
spacebar - pause/unpause
```
-----

# Dependencies

- **Python**
- **FFmpeg** - Audio
- **figlet** - ASCII Banner
- **lolcat** - Rainbow Gradients
